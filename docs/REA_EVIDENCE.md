## 8. Limites et inconnues
- Inventaires Ghidra : uniquement données typées en chaînes ; les chaînes UTF-16 (dialogues W) et les tables non typées (mots-clés CLI, formats "%s (%s)") peuvent manquer → recherches `PuTTY Alert`, `%s (%s)`, `-ssh` brut = vides **sans prouver l'absence**.
- Pseudocode = décompilation, pas la source ; constantes par défaut chiffrées non retrouvées statiquement (utilisées depuis la table de conf) → compensées par `[RUNTIME]` (schéma + valeurs complètes sauvegardées), les valeurs d'une session pouvant être modifiées par l'utilisateur.
- Aucun test d'exécution du binaire (pas de trace dynamique) ; pas de vérification de signature Authenticode (non demandée).
- Titre après login `user@host` + gestion OSC titre : cohérent avec `WinNameAlways`, `NoRemoteWinTitle`, `RemoteQTitleAction` `[RUNTIME/OBS]`, format exact non extrait.
